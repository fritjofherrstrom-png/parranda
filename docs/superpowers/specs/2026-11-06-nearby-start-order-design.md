The user approved continuing the diagnosed start-order correction after the
public Floss reproduction: a selected bar about three metres from the planning
anchor appeared last although a first-stop variant had the same geometry score.

For an ordinary any-place loop, when geometry objectives are exactly equal,
prefer the order with the smaller first gap from the established planning
anchor. Keep the same admitted stops and the existing primary objective.
This is a tie-break, not a new distance allowance, GPS watch or source rule.

Use a private optimizer option enabled only by agnostic composition with no
manual day edit. Legacy/template calls and arcs retain their ordering. Apply the
same comparison to candidates evaluated by the already bounded large-stop
refinement, keeping its strict-improvement search cursor unchanged. Do not
increase permutation limits, passes, source work or published distance claims.

Existing later daypart, source-hours, meal, manual-edit, event and final walking
checks remain authoritative. An explicit current-day edit is left intact.

Alternatives considered: always forcing the nearest place first can worsen a
route or conflict with time; raising proximity ranking cannot correct a final
geometry tie. The chosen correction resolves that tie at its existing owner.

The previously diagnosed catalogue identity/coverage gaps and new persistent
visited/rating feature remain separate subsequent work. No UI, source policy,
merge or deployment belongs to this candidate.
